# Seams Club: Pattern directory and pattern page

Upload this folder to your Replit project at `docs/design/patterns/`, then paste the part of `PROMPT.md` below the line into Replit Agent.

- `images/`: screenshots at 2× scale for desktop (`d1`–`d7`) and mobile (`m1`–`m7`).
- `screens/`: static snapshots as standalone HTML pages.
- `source/`: the interactive mockups, for reference.

# SewSpace design reference

Source of each mockup screen from the design canvas, one file per screen.
Use these for exact colours, spacing, radii, copy and component structure.
They are design references, not production code: they use a mockup runtime
(`support.js`, `<x-dc>`, `{{holes}}`) that is not part of this app, and image
URLs (`/_blob/...`) will not load here.

Do not copy any photos into the app. Mockup photos were Instagram screenshots
used for illustration only.

# Seams Club: My studio mobile screens

Put this folder in the repo at `docs/design/studio-mobile/`, then give Claude Code the text of `PROMPT.md`.

- `screens/`: the five screens as standalone HTML pages. Open any of them in a browser; the section pills link between them.
- `images/`: screenshots at 2× scale, including the interactive states.
- `source/`: the interactive mockup files, for reference.

# Seams Club: Account menu

Put this folder in the repo at `docs/design/account-menu/`, then give Claude Code the text of `PROMPT.md`.

- `images/`: screenshots at 2× scale for desktop (`d1`–`d3`) and mobile (`m1`–`m3`). They show the menu open, closed, and asking to confirm log out.
- `screens/`: static snapshots of the open menu as standalone HTML pages.
- `source/`: the interactive mockups, for reference.

# Seams Club — form flow designs

Put this folder in the repo at `docs/design/flows/`, then give Claude Code the text of `PROMPT.md`.

- `PROMPT.md` — the build instructions (Phase F, parts F0 to F4)
- `images/` — a screenshot of every step. `-m-` means mobile (390 px wide, at 2× scale) and `-d-` means desktop (1440 px wide).
- `screens/` — the interactive mockups (Design Component files). They are for reference only.
